# Unslop

Clean prose without flattening its voice. This is a prose pass, not code contribution proof or a substitute for testing and review.

## Process

1. Rewrite to preserve meaning, facts, conditions, warnings, and intended voice.
2. Replace filler, puffery, vague attribution, formulaic contrasts, and chatbot language with concrete claims.
3. Use plain active language. Remove needless jargon, hedging, repeated synonyms, decorative punctuation, and generic conclusions.
4. Read the result once more and state any evidence gap directly.

## Completion

The prose is clean when it preserves the source's meaning and evidence, removes the listed AI patterns that do not serve the text, uses concrete active language, and passes one final read without generic filler, decorative punctuation, or an artificial conclusion.
