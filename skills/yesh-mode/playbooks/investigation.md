# Investigation

Use for explanations, diagnosis, reviews, and recommendations without implementation.

Answer from the relevant evidence. Use [how](../../how/SKILL.md) for a substantial execution trace or inventory, [why](../../why/SKILL.md) for historical rationale, or [structure review](../../structure-review/SKILL.md) for an engineering audit when those methods help.

Define a completeness boundary for broad inventories. Follow the evidence far enough to resolve the question; do not search every possible source for a narrow answer.

Lead with the answer and supporting locations. Distinguish direct evidence, inference, and unresolved gaps. A recommendation does not authorize applying it. If implementation is already part of the request, continue into that work after the investigation.
