# Prototype

Use to answer a design or empirical question with disposable work.

State the question and what observation would settle it. Build the smallest artifact that can produce that observation. Reuse project tools where practical and keep experimental output separate from production paths.

Compare alternatives when the choice matters. For visual alternatives, labels and a shared switcher can help the user give a precise verdict. Match the number and form of alternatives to the uncertainty.

Exercise the artifact, report what was learned, and identify the chosen direction or remaining question. A prototype establishes feasibility or preference, not production readiness. Carry it into production only when that work is requested.
