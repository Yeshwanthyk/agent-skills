# Authoring a skill

Use to create or change skill instructions or their supporting resources.

Read the target and the current skill-creator guidance when available. Identify the requested capability, its trigger, and the information the model cannot reliably supply on its own.

Keep discovery short and specific. Put shared purpose and constraints in the entrypoint; route substantial conditional detail to references. Preserve the user's scope and existing invocation policy. Reuse available scripts and assets when they improve reliability.

Remove repeated guidance, mandatory skill chains, and fixed steps that do not protect correctness or the requested method. A useful completion condition is more valuable than an itinerary.

Validate the changed frontmatter and links. Run changed scripts and inspect their outputs. For a substantial behavioral change, use an independent realistic task when it can add confidence within the available resources. Judge outcomes rather than instruction citations.

Finish with the change and its evidence. PR work starts only on request.
