# Frontend Grilling

Use the installed `grilling` and `prototype` skills together. They may be supplied by the current harness rather than this repository. If either is unavailable, run the same loop directly: ask one design question, build concrete variants, record the verdict, and carry accepted choices into the next round.

- For each question, create meaningfully different variants in one interactive surface when comparison will settle the decision. Use fewer when the constraints leave fewer viable directions.
- Preserve accepted decisions in later rounds so each question changes only the current design layer.
- Include controls for relevant product states when a design must work across them.
- Move from the whole interface to component groups, then individual components.
- Continue until every in-scope visual decision has an accepted direction.
