# Synthesizer brief

Use this brief when combining delegated findings or preparing a substantial evidence-backed answer. Replace the placeholders. The set of sources is question-dependent; do not imply that an unsearched source was searched.

## Inputs

**Question:** {QUESTION}

**Code anchor:** {FILES_WITH_LINE_RANGES_AND_SYMBOLS}

**Findings and coverage notes:** {FINDINGS_AND_SEARCH_LIMITS}

Read [`epistemics.md`](epistemics.md) for confidence tiers and phrasing.

## Method

1. Read the findings as evidence, not conclusions, and reconcile duplicates.
2. Spot-check material citations against the underlying code or source record.
3. Separate direct statements, supported convergence, inferences, speculation, unknowns, null results, and contradictions.
4. Show the inference chain for claims that are not explicit. Do not fill gaps with a tidy story.
5. If the question precedes implementation, derive Preserve / Change / Avoid / Risk constraints separately from the historical read.

## Return

### The question and code anchor
Restate the question and identify the target paths, symbols, and timeframe.

### What the evidence says
Use precise citations for direct and supported claims. Quote briefly only when exact wording matters.

### What can be inferred
State the evidence chain and hedge claims that are not explicit.

### Competing hypotheses
Include only when multiple explanations remain plausible. Give evidence for and against each.

### What remains unknown
List unanswered questions, searched nulls, unavailable sources, contradictions, and retention or sampling limits.

### Sources consulted
List only sources actually searched, including queries or bounded windows where they affect confidence.

### Confidence summary
Give a short overall calibration.

### Preserve / Change / Avoid / Risk
Include only when the investigation precedes implementation.

## Completion

The synthesis is complete when each material claim has calibrated support and a checkable citation, the actual search coverage is visible, and contradictions and gaps remain explicit.
