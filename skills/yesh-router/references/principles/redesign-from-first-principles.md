# Redesign from first principles

**Read when:** integrating a change into an existing design, where bolting the change on would distort the design.

- Read all affected files and understand the current design holistically.
- Ask: if this requirement had been there from day one, what would we have built?
- Propagate the change through every reference: types, docs, examples, rationale sections.
- Redesign holistically, then deliver incrementally.

**Limits:** this integrates a new requirement into a design; choosing among candidate shapes is [exhaust-the-design-space](exhaust-the-design-space.md).
