# Pause safely

Use when the user asks to pause. A request to keep working through the user's absence belongs to [autonomous run](autonomous-run.md).

Reach a safe boundary without starting new work. Settle or cancel managed writers and confirm their state before describing the pause. Preserve existing edits and name any incomplete or broken portion.

Write a short resume note with the objective, current state, completed proof, outstanding work, owned paths, and first next action. Reuse an existing decision trail when it already supplies the record.

A pause does not require a commit, push, or PR. Use an existing authorization only if that action is needed to preserve the requested work.

Finish with the resume location and any unresolved worker or partial-state risk.
